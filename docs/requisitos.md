# Requisitos

## Fase 1 – Sitio web
- Como visitante quiero ver qué servicios ofrece la agencia para decidir si la contrato.
- Como visitante quiero ver ejemplos de trabajos (portafolio) para confiar en la agencia.
- Como visitante quiero un formulario de contacto para solicitar una cotización.
- Como agencia quiero SEO básico y analítica para medir de dónde llegan los clientes.

## Fase 2 – Plataforma interna (por detallar)
- Gestión de clientes.
- Proyectos y campañas con estado y responsables.
- Cotizaciones y facturación.
- Autenticación para el equipo.
