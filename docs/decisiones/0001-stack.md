# ADR 0001: Stack tecnológico

**Decisión:** Next.js (App Router) + TypeScript + Tailwind CSS, desplegado en Vercel.

**Motivos:** un solo framework para web y backend, buen SEO (clave en marketing), despliegue sencillo y gratuito al inicio.

**Fase 2:** Postgres (Neon/Supabase) con Prisma y autenticación.
