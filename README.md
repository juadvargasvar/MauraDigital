# Maura Digital

Agencia de marketing digital fundada por Maura Alejandra (Administradora de Empresas, USCO) y Juan David (Administrador de Sistemas UNAL, estudiante de Ingeniería de Software USCO).

## Fases
1. **Sitio web** (`web/`): página pública con servicios, portafolio y contacto.
2. **Plataforma interna** (`app/`): clientes, proyectos/campañas, cotizaciones y facturación.

## Stack
Next.js (App Router) · TypeScript · Tailwind CSS · Vercel. Fase 2: Postgres + Prisma + autenticación.

## Cómo correr el sitio
```
cd web
npm install
npm run dev
```

## Documentación
- `docs/negocio/`: servicios, marca, público objetivo, precios.
- `docs/requisitos.md`: historias de usuario por fase.
- `docs/decisiones/`: decisiones de arquitectura (ADRs).
